# indirect — мастерская маркетинговых фабрик

Монорепо фабрик крео и лендингов Тараса. Текущая сборка: `music-vsl-cloner` —
конвейер обратного инжиниринга музыкальных сторителлинг-VSL: декодирует
видео-референс по семи слоям ДНК и пересобирает ролик либо локализацией
(режим A), либо под новый продукт (режим B). Генерация — через kie.ai
(Suno для песни, Seedance 2.0 Mini 480p для видео).

Прошлая сборка `video-dna-factory` остановлена по решению пользователя
2026-08-17 и в новой не переиспользуется; её след — `.autopilot/video-dna-factory/`.

## Как здесь работает Autopilot

Сборка ведётся навыком `/autopilot`. Требования, спецификация и таски — в `.autopilot/`.
Прогресс — `.autopilot/dashboard.html`. Правило: требование из `manifest.md`
может снять только пользователь.

Если работа продолжается — скажи «продолжи автопилот»: состояние поднимется
из `.autopilot/state.js`, переспрашивать ничего не нужно.
