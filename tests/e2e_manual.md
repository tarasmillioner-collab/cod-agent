# E2E вручную (тест-бот + тест-группа, LPCRM_DRY_RUN=1)

Підготовка: config.env (BOT_TOKEN тест, ANTHROPIC_API_KEY, MANAGERS_CHAT_ID тест-групи з темами, ADMIN_IDS), `python bot.py`.

| # | Дія | Очікування |
|---|-----|-----------|
| 1 | Відкрити `t.me/<bot>?start=s1_fb_test123` | Привітання з «Сироватка Olavita — 590 грн», кнопки «Так, оформити» / «Змінити набір» |
| 2 | «Так, оформити» | Прохання номера + reply-кнопка «📱 Поділитися номером» |
| 3 | Надіслати контакт | «Як до вас звертатися — <ім'я>, правильно?» |
| 4 | «Так» | «У яке місто відправити?» |
| 5 | Написати «Бровари» | Список міст (кнопки) або «Бровари, правильно?» |
| 6 | Обрати місто | Список відділень + «🔎 Інше відділення» / «Поштомат» |
| 7 | Написати «4» | Відділення №4 зафіксовано → апсейл «крем для очей… 1 089 грн» (якщо не ніч) |
| 8 | «Лише сироватка — 590 грн» | Підсумок з повною касою, кнопка «✅ Підтверджую — 590 грн» |
| 9 | «Змінити» → «Місто / відділення» | Повернення на крок міста |
| 10 | Дійти до підсумку, «Підтверджую» | Квитанція: №, сума, «5 робочих днів», «скасувати до відправки», «дзвонити не будемо» |
| 11 | Лог: `LPCRM DRY_RUN addNewOrder` | payload: status=11, products 333, delivery_adress «м. Бровари…, Відділення №4…», additional_2=test123 |
| 12 | Написати «а є знижка?» | Відповідь без знижки, ціна лише 590/1089/1388, без «стара ціна 1997» |
| 13 | Написати російською «сколько идет доставка?» | Відповідь українською, «1–3 дні», без конкретного дня |
| 14 | «Передзвоніть мені» | «Передаю колезі…»; у групі — нова тема з карткою; відповідь менеджера в темі приходить клієнту |
| 15 | `/close` у темі | Бот знову відповідає клієнту |
| 16 | `/bot off` у групі, новий клієнт пише | Клієнту «менеджер відповість», тема в групі, LLM не викликається |
| 17 | `/bot on`, `/stats` | Воронка з числами |
| 18 | Новий клієнт, дійти до міста і замовкнути на 15 хв | Nudge «я тут… лишилося N кроки» з кнопками |
| 19 | «Не цікаво» | «більше не турбуватиму», замовлення скасовано |
| 20 | Написати «скасувати» після підтвердження (до ТТН) | «Скасувала…», стадія cancelled |
